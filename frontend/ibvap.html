Problem Statement

IBVAP Background

Why this platform exists

CCTV systems mainly record and display video, requiring continuous human monitoring and making it difficult to detect every security incident.

Intelligent features like intrusion detection, object tracking, facial recognition, and ANPR often depend on costly specialised hardware and proprietary systems.

This makes intelligent surveillance expensive and difficult to scale, especially across remote and challenging border locations.

There is a need for a cost-effective, software-based AI solution that can use existing CCTV cameras to detect, track, analyse, and alert security forces about potential threats in real time.

Proposed Solution
02

What IBVAP does

IBVAP is an AI-driven software platform that converts existing CCTV infrastructure into an intelligent surveillance network — without requiring dedicated FRS, ANPR, or smart-camera hardware.

The platform ingests live video streams from standard IP-based CCTV cameras and runs real-time video analytics using computer vision and machine learning, directly on top of the feeds that are already running.

Everything the system detects — a person crossing a virtual fence line, a vehicle plate, movement after dark — becomes a logged, timestamped, actionable event instead of a frame someone has to notice manually.

Built to be cost-effective, scalable, and deployable across remote border locations and strategic installations.

How intrusion detection works

IBVAP observes the live stream, maps a virtual fence across the scene, and creates an event when a tracked person or vehicle crosses the defined boundary.

  1. 01 Detect people and vehicles in each frame.
  2. 02 Track movement against the virtual boundary.
  3. 03 Raise an alert when the line is crossed.
  4. 04 Log the event for later review.
